# Notes 写作与版式规范

## 用途与适用范围

Notes 用于已完成的技术调研、学习记录、实验方法和计算记录。调研仅归入 Notes，不在 Projects 重复建条目。本文是当前规范，取代此前纸张式阅读器的说明。

三篇调研共用 Just the Docs 官方样式、导航与搜索脚本。正文按章节组成独立页面；页面之间通过侧栏、面包屑和文档首页联系，不采用纸张、页码或连续跨章正文。

## 内容组织与标题

文档首页提供正式标题、副标题、分类标签、摘要及章节入口。正式标题应说明对象与范围；侧栏使用简短文档名。章节标题优先简短、明确，旧长标题可保留为副标题，避免导航出现整句说明。

章节内采用 H2、H3 层级；每个页面只有一个 H1。短小节保留在所属章节，篇幅较长且可独立阅读的小节可单独成页。医学报告按应用领域分章；电子—电子距离报告保留 17 章，不将全部 H3 拆成独立页。

正文保留背景、理论或方法、实验条件、结果、适用范围及限制。参数应给出名称、单位和条件；案例注明实际样品、方法、观测结果和原来源。区分已有结论、假设及待核实信息，不补造文献或实验事实。已完成调研不使用“正在调研”等状态表述。格式迁移不得改写谱学结论、实验参数或相位表。

## 元数据与内容管理

原报告正文的唯一编辑来源位于 `_note_sources/<slug>.html`，保留 YAML 标题、summary、category、tags、featured、order 与可选日期。主站首页和 Notes 列表从生成的 `_notes/<slug>.html` 读取同一份元数据。空日期不显示；日期应明确代表文档发布或更新，不能代替文献检索截止日期。

```yaml
---
layout: note
title: 文章标题
summary: 简短摘要
category: 磁共振
tags: [EPR]
featured: false
order: 1
published_at: null
updated_at: null
math: true
---
```

当前迁移使用 `scripts/build-note-docs.py <slug>` 生成文档主页、章节、搜索索引和旧锚点映射。生成的 `_notes/`、`notes/<slug>/` 不直接修改。新报告需在生成脚本中配置文档标题、章节摘要标题与分章方式，不能机械按每个 H3 分页。图片及附件保存在 `assets/notes/<slug>/`，用固定的小写路径引用。

## 视觉与导航

使用 Just the Docs 原生响应式布局：桌面整体居中、两侧留空，正文左对齐；移动端使用折叠菜单。保留原生字体层级、搜索框、面包屑、多级导航和章节锚点，不另设阅读比例、自动缩放控件或纸张尺寸。

ICO 返回 `/`；侧栏文档标题返回该文档首页；侧栏底部“返回 Notes”进入 `/notes/`。仅有子页面的条目显示展开箭头，避免空目录。每页页底包含 Back to top、版权及 Just the Docs 来源链接。

共享主题存于 `assets/jtd/note-themes.css`，主题设置使用滑杆图标及色点，不显示主题名称。默认 mist，以主页蓝灰、暖白为基调，图标保留金色；保留 sage、sand、mauve、gray，选择保存到浏览器。原报告的布局 CSS 不加载；专业图示确有需要时仅补充图示局部规则。

## 公式、表格与图示

公式使用 `\(...\)` 与 `\[...\]`，保留分隔符。目录展示不能复用去除分隔符的搜索纯文本转换。MathJax 配置中的反斜杠必须按 JavaScript 字符串规则转义。公式与中文标点、连续公式和带下标标题均应实测。

长公式按正文可用宽度缩小；行内公式整体换行，不添加滑块。长公式过密时应在源文中按数学项合理分行。表格按内容宽度居中，长单元格换行，确实超宽时允许表格局部滚动；不能撑宽整页。保留表格、相位表、代码、SVG 和参考文献链接。图表必须有适用条件和单位，不用装饰性图片替代科学数据。

文档搜索采用原生 Lunr 结果界面，覆盖该文档各子页，并用中文分词保留中文检索。检索数据与正文同时生成，不另维护重复摘要。

## 发布与检查

更新源文后运行对应生成命令，再运行 `git diff --check` 与共享 JS 语法检查。可用 Jekyll 环境运行 `bundle exec jekyll build`；部署由 GitHub Pages 编译。

发布前检查：单一 H1、内部页面和锚点、表格数量、案例与文献链接、数学分隔符、每页完整版权。浏览器检查中文与英文搜索、导航、主题切换、窄屏、长公式和表格。页面必须可直接读取静态正文；MathJax、Mermaid 和交互功能依赖脚本成功加载。不得把静态检查写成浏览器验收。

当前正式入口为 `/notes/w-band-epr/`、`/notes/x-band-epr-medical/`、`/notes/electron-electron-distance/`。独立预览保留作对照，正式页面不引用预览目录中的资源。
